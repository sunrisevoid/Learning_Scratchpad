== operator asks if two values are the same as each other, whereas
= assigns the value on the right to the left

*Boolean values* - only two values, **True** or **False**
*Comparison operators* - always two characters; ==, <=, !=, etc;
*Boolean operators* - only three: **and**, **or**, and **not**.

Flow control statements
often start with a part called the *condition*, which is followed by the *clause*

## Terminal Notes

~ user directory
/ root
. current working directory

**ASCII** means American Standard Code for Information Interchange
symbolic link or symblink, is a file that simply points to another file, useful for files that are updated frequently with new names but you still need access to the file by the original name.

~~~
Wildcards:
* means - all files
a* means - any file beginning with letter
a*b means - any file beginning with b and ending with specific characters
? matches - any single characters
[abc] - matches any characters in brackets
[!abc] - excludes characters in brackets
[[:class:]] - matches any character of a specific class
~~~

cp means copy. *cp item1 item2*

-r recursive, it is called recursive because it repeats the same action for every directory it finds.
-i interactive, prompt the user for confirmation before deleting a file.
